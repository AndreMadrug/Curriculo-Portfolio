# Currículo / Portfólio

Site pessoal de currículo e portfólio de André Nascimento, desenvolvido com Next.js (App Router) e CSS Modules.

**Site publicado:** https://curriculo-portfolio-nqny.vercel.app

## Páginas
- Home
- Sobre (tecnologias e módulos usados)
- Experiência Acadêmica
- Experiência Profissional
- Projetos Desenvolvidos (repositórios carregados pela API do GitHub)

## Tecnologias
Next.js, React, CSS Modules, next/font, GitHub REST API, Vercel.

## Como rodar
```bash
npm install
npm run dev
```
